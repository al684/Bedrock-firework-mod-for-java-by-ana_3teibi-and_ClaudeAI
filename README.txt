طريقة تحويل المشروع إلى مود (ملف jar)
=========================================

هذا مشروع مصدري (Source). المود نفسه ملف .jar ينبني منه.
وهو مب Resource Pack: الريسورس باك يغير الشكل والأصوات بس، وما يقدر يغير الفيزياء.

المتطلبات
---------
1) Java 17 (JDK)
2) Gradle 8.x  (أو افتح المجلد في IntelliJ IDEA وهو يجهز كل شي)
3) اتصال بالإنترنت أول مرة (يحمّل Fabric و Minecraft)

البناء
------
  cd bedrock-fireworks
  gradle build

الملف الناتج:
  build/libs/bedrock-fireworks-1.0.0.jar
(لا تاخذ الملف اللي فيه -sources)

التركيب
-------
حط الملف في مجلد mods، وتحتاج:
  - Minecraft Java 1.20.1
  - Fabric Loader 0.15.x أو أحدث
  - Fabric API

الاستخدام
---------
- داخل اللعبة اضغط K لفتح شاشة الإعدادات (تقدر تغير المفتاح من Controls).
- الإعدادات تنحفظ في: config/bedrockfireworks.properties

ملاحظة عن الخط العربي
---------------------
إذا طلعت الحروف العربية مقطّعة، غيّر لغة اللعبة إلى العربية
(Options > Language > العربية) وبتتصلح.

لو ما تبي تنزّل أي شي على جهازك (بناء عن طريق GitHub)
------------------------------------------------------
1) سوّ حساب على github.com وأنشئ Repository جديد
2) ارفع محتوى المجلد كله (بما فيه المجلد المخفي .github)
3) ادخل تبويب Actions وانتظر دقيقتين لين يخلص البناء
4) افتح آخر تشغيل ونزّل bedrock-fireworks-jar من قسم Artifacts
